## 🚀 Bina Technical Knowledge Ke GitHub Par Kaise Upload Karein (2-Minute Step-by-Step Guide)

1. Apne browser mein apni repository kholein: [https://github.com/Kuldeepsharma9130/haryanaroadwaystimetable](https://github.com/Kuldeepsharma9130/haryanaroadwaystimetable)
2. Wahan **Add file** button par click karein aur **Upload files** chunein (ya *uploading an existing file* link par click karein).
3. Yahan di gayi teeno files (`index.html`, `haryana_roadways_timetable.csv`, aur `README.md`) ko drag-and-drop karke select karein.
4. Neeche green रंग ke **Commit changes** button par click kar dein — aapka saara data aur table seedha GitHub par save ho jayega!
5. **Live Website Chalu Karne Ke Liye:** Repository ke upar **Settings** tab mein jayein → left menu mein **Pages** par click karein → **Branch** ke neeche `None` ki jagah `main` (ya `master`) select karke **Save** dabayein. 1 minute mein aapki website live ho jayegi!
